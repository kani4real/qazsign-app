# QazSign — веб-қосымша (Streamlit)

Қол ым-ишарасын камерадан тануға арналған веб-қосымша. Үш бөлімнен тұрады:
деректер жинау → модельді оқыту → тікелей тану/дауыстау.

## 1. Компьютерде сынау (GitHub-қа жүктемей тұрып тексеру үшін)

```bash
pip install -r requirements.txt
streamlit run app.py
```

Браузерде `http://localhost:8501` ашылады. Камераға рұқсат сұралғанда — рұқсат етіңіз.

## 2. Бір сілтеме арқылы ашылатын веб-нұсқа жасау (GitHub + Streamlit Community Cloud, тегін)

### Қадам 1 — GitHub-қа жүктеу
1. https://github.com сайтында тіркеліңіз (аккаунт жоқ болса).
2. Жаңа репозиторий жасаңыз, мысалы `qazsign-app` (Public етіп қойыңыз — тегін жоспарда солай керек).
3. Осы қалтадағы барлық файлды (`app.py`, `qazsign_features.py`, `requirements.txt`, осы README) сол репозиторийге жүктеңіз. Ең оңай жолы — GitHub сайтындағы **"Add file → Upload files"** батырмасы арқылы файлдарды тікелей сүйреп апару (drag-and-drop).

### Қадам 2 — Streamlit Community Cloud-қа қосу
1. https://streamlit.io/cloud сайтына кіріп, GitHub аккаунтыңызбен кіріңіз (тегін).
2. **"New app"** батырмасын басыңыз.
3. Repository — өзіңіздің `qazsign-app` репозиторийіңізді таңдаңыз.
4. Branch — `main`, Main file path — `app.py`.
5. **"Deploy"** басыңыз. 2-5 минут күтіңіз (кітапханалар орнатылады).
6. Дайын болғанда сізге мынандай сілтеме шығады:
   `https://qazsign-app-XXXXX.streamlit.app`

Осы сілтемені кез келген адамға, оның ішінде конкурс жюриіне жіберуге болады — олар өз браузерінен ашып, өз камерасымен сынап көре алады.

## 3. Маңызды ескертулер

- **Камера рұқсаты**: сайт HTTPS арқылы жұмыс істейді (Streamlit Cloud автоматты түрде береді), сондықтан браузер камераны қауіпсіз рұқсат етеді.
- **Деректер сақталуы**: Streamlit Cloud-тағы файлдар уақытша (қайта іске қосылғанда өшуі мүмкін). Сондықтан деректер жинағаннан кейін міндетті түрде **"⬇️ CSV жүктеп алу"** батырмасын басып, csv файлды өз компьютеріңізде сақтап қойыңыз — қажет болса, кейін "жүктеу" арқылы қайта қосасыз.
- **Модельді жаңарту**: 2-бетбелгіде модельді қайта оқытқаннан кейін, 3-бетбелгідегі камера терезесін **тоқтатып (Stop), қайта қосу (Start)** керек — сонда жаңа модель жүктеледі.
- **Камера қосылмай тұрса**: кейбір мектеп/корпоративтік Wi-Fi желілерінде WebRTC бөгеледі. Мұндай жағдайда үй интернетінен немесе телефонның мобильді интернетінен ашып көріңіз.
- **Дауыс (TTS)**: интернет қажет (gTTS Google серверіне жүгінеді). Толыққанды қазақша дауыс жоқ болғандықтан, орысша дыбысталады, ал экрандағы мәтін әрдайым қазақша.

## 4. Файлдар құрылымы

```
qazsign-app/
├── app.py                 # негізгі Streamlit қосымшасы (3 бетбелгі)
├── qazsign_features.py    # ортақ фича-инженерия функциясы
├── requirements.txt       # Streamlit Cloud осыдан кітапханаларды орнатады
└── README.md               # осы файл
```
